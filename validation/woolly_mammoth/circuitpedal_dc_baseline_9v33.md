# CircuitPedal Woolly Mammoth DC baseline at 9.33 V

This baseline was generated by the V0.19 `circuitpedal_validate dc-check`
workflow against `working_board_dc.csv` with all four Woolly controls at maximum
and the validation-only source override `VCCSRC=9.33`.

The corresponding macOS CI run completed the full ten-test suite, the Woolly DC
report and the GUI bundle check successfully.

## Interpretation

This is a useful diagnostic split rather than a fidelity pass.

- Q1 base and Q2 emitter are already within approximately the published 10%
  working-board neighbourhood.
- Q1 collector/Q2 base is too high by about 23%.
- Q2 collector is too low by about 25%.
- The present machine gate remains 35% so these differences stay visible as
  fidelity work rather than being hidden by parameter fitting solely to make CI
  pass.

The supply mismatch has been removed from this comparison, so the next
investigation should focus on the compact 2N3904 model, transistor bias/current
interaction and then an independent SPICE reference before changing circuit
topology or tightening the gate.

This file is a CircuitPedal baseline, not an independent reference. It must not
be used as golden data for validating CircuitPedal against itself.
